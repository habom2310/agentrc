# agentrc hub check prompts

Paste one of these into a **fresh** session of each AI. Each one should answer PASS/FAIL per item.

Hub: `~/.agentrc` (rules, agents, skills, MCP). Claude Code can be checked the same way with a fresh `claude -p` session.

Paths below assume agentrc is cloned at `~/Documents/agentrc`; adjust to where you cloned agentrc.

---

## Antigravity (agy / Gemini)

```text
Verify my centralised agentrc hub setup. Do not modify any files. Report PASS/FAIL per item, terse.

1. From your loaded global rules only (no tools): quote the section headings you see. Expected to include "Coding guidelines", "Long-running commands: watchdog", "Code tools: one tool per moment", "CodeGraph", "Handoff after each work item", "Subagents", "Web Search & Image Generation", "PR review with Copilot". The first line of ~/.gemini/GEMINI.md should be an AUTOGENERATED BY AGENTRC header.
2. List the custom subagents you can delegate to. Expected: implementer (inherit), reviewer (pro), scout (flash) projected into ~/.gemini/config/agents/, plus agy's own research agent (not from the hub).
3. List the skills you can load. Expected: handoff, ripwire-change-check, ripwire-find-bug, ripwire-quality-bar, ripwire-reuse-first, ripwire-write-tests, all served from ~/.agentrc/skills (see ~/.gemini/config/skills.json).
4. Open the skill ripwire-find-bug and quote the first line of its description.
5. Check MCP: is the codegraph server connected? Call its explore tool with query "project_subagents" and projectPath "~/Documents/agentrc"; say whether it returned source.
6. Delegate to the scout subagent: "Run `ls -la ~/.agentrc` and report the entries." Report whether the subagent started without a tool-registry error, and what it returned.
```

## OpenAI Codex CLI (after installing Codex)

Codex wasn't installed when the hub was set up. First run:

```bash
python3.12 ~/Documents/agentrc/agentrc.py link && python3.12 ~/Documents/agentrc/agentrc.py project
```

Then in Codex:

```text
Verify my centralised agentrc hub setup. Do not modify any files. Report PASS/FAIL per item, terse.

1. From your loaded global instructions (~/.codex/AGENTS.md) only: quote the section headings. Expected to include "Coding guidelines", "Code tools: one tool per moment", "Handoff after each work item", and "Codex Defaults & Overrides".
2. Does the agy path in your instructions read ~/.local/bin/agy (not an AppData .exe path)?
3. List the skills you can use. Expected: handoff and the five ripwire-* skills from ~/.codex/skills -> ~/.agentrc/skills.
4. Run `ls -la ~/.codex/skills` and confirm it is a symlink to ~/.agentrc/skills.
```

## ChatGPT (web / desktop)

Paste the contents of `~/.agentrc/export/chatgpt_custom_instructions.md` into Settings → Personalization → Custom instructions (or a Project's instructions). Then ask:

```text
Without browsing, summarise in 5 bullets the working rules in my custom instructions: how I want coding changes scoped, how to handle long-running commands, which code tools to use when, and when to write a handoff. Then state the agy binary path you were given.
```

Expected: surgical/simple changes, the watchdog command, the CodeGraph/ripwire table, handoff after substantial work, `~/.local/bin/agy`.
