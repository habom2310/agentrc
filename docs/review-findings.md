# Independent Architectural Review Findings & Resolutions

This document records the architectural review performed on the initial `agentrc` specification by the `reviewer` subagent (Pro model) on 2026-10-24, and the resulting architectural resolutions.

---

## 1. Blocking Defects Found & Resolved

### Defect 1: Antigravity Ingestion Mechanics (`GEMINI.md`)
- **Finding**: Antigravity has no markdown preprocessor or `@import` transclusion engine. AGY directly ingests `~/.gemini/GEMINI.md` into `<RULE[user_global]>`. Placing `@~/.agentrc/rules/common.md` inside `GEMINI.md` results in AGY reading the literal text of the import line rather than importing the file.
- **Resolution**: **Compiled Projection**. `agentrc` deterministically projects `GEMINI.md` by assembling:
  `rules/common.md` + `rules/code-tools.md` + `rules/handoffs.md` + `rules/overrides/agy.md`
  Prefixed with an autogenerated header guard:
  `<!-- AUTOGENERATED BY AGENTRC - DO NOT EDIT DIRECTLY. EDIT IN ~/.agentrc/rules/ -->`

### Defect 2: Subagent Frontmatter Schema Incompatibility
- **Finding**: Claude Code and AGY have mutually exclusive YAML frontmatter schemas:
  - Claude Code requires `tools: Bash, Read, Edit...` and model identifiers like `model: claude-haiku-5-5`.
  - AGY rejects unknown tool keys like `call_mcp_tool` (crashes executor: `unknown component: tool "call_mcp_tool" not found in registry`) and expects tier values like `inherit`, `pro`, or `flash` with omitted native tool declarations.
  - A raw directory junction between `~/.claude/agents` and `~/.gemini/config/agents` breaks schema validation on one or both platforms.
- **Resolution**: **Host-Adapted Projection**. Store universal agent definitions in `~/.agentrc/agents/` with tier aliases (`fast`, `pro`, `inherit`), then project target-specific `.md` files into `~/.claude/agents/` and `~/.gemini/config/agents/`.

### Defect 3: Claude Code Hook Configuration Discovery
- **Finding**: Claude Code does not discover hooks placed inside a generic directory named `~/.claude/hooks/`. Claude Code hooks must be explicitly registered inside `~/.claude/settings.json` under the `"hooks"` key.
- **Resolution**: `agentrc` configures hooks directly in `~/.claude/settings.json` (for Claude) and `~/.gemini/config/hooks.json` (for AGY).

### Defect 4: Windows Hard Link (`mklink /H`) Fragility
- **Finding**: Text editors and modern tools save files via atomic replacement (`write temp -> rename`). This operation breaks NTFS hard links on individual files.
- **Resolution**: Use **NTFS Directory Junctions (`mklink /J`)** for directories (such as `skills/`), which require zero administrator privileges and are immune to file replacements. For individual files, use **compiled projection** rather than file links.

## 2. Operational Improvements Adopted

1. **Non-Interactive Hook Fail-Safe**:
   - `SessionStart` hooks run headless in the background and must never invoke interactive prompts (`input()`) or block on `stdin`. If a conflict occurs, emit a one-line warning directing the user to run `agentrc doctor`.
2. **Whitelist Migration Backup**:
   - `~/.gemini` contains multi-gigabyte `brain/` logs and caches. Pre-migration snapshots must strictly whitelist target configuration files (`*.md`, `*.json`) rather than creating recursive tree copies.
3. **Preservation of Multi-Agent Bridges**:
   - Cross-agent delegations (e.g. Claude Code delegating images to `agy` and PR reviews to `copilot`) are intentional federation superpowers. They are partitioned into `rules/overrides/<tool>.md` rather than being stripped.
4. **Token Boot Budget Discipline**:
   - Keep session boot context under ~1,200 tokens across all tools via progressive disclosure (name + description only for skills), silent `<200ms` hooks, and on-demand procedural skills.
